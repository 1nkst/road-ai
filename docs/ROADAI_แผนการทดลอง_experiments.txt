================================================================================
 ROAD AI — แผนการทดลอง (ฉบับฟิสิกส์)
 หมวด: วิทยาศาสตร์กายภาพ (Physical Science)
 แกนหลัก: ทัศนศาสตร์และการวัด (Optics & Measurement) + แสง/การสะท้อน + ปริมาณทางฟิสิกส์
================================================================================

แนวคิด: ROAD AI คือ "เครื่องมือวัดเชิงแสง" ที่แปลงภาพจากกล้องให้เป็นขนาดจริง
ด้วยหลักทัศนศาสตร์ (แบบจำลองกล้องรูเข็ม + การฉายภาพเชิงมุม/โฮโมกราฟี) แล้วต่อยอด
เป็นปริมาณทางฟิสิกส์ (พื้นที่ → ปริมาตร → มวล) การทดลองชุดนี้พิสูจน์ว่าปัจจัยทาง
ฟิสิกส์ใดบ้างที่มีผลต่อความแม่นยำ และระบบแม่นยำเพียงใด

รูปแบบทุกการทดลอง:
  วัตถุประสงค์ • สมมติฐาน • ตัวแปรต้น/ตาม/ควบคุม • หลักฟิสิกส์ • วิธีทำ •
  ตารางบันทึกผล • การวิเคราะห์
เครื่องมืออ้างอิง (ground truth): ไม้บรรทัด/เวอร์เนีย, ตาชั่ง, แอปวัดความสว่าง (lux)

 รายละเอียด + ตารางบันทึกผล

── การทดลองที่ 1: ผลของความสูงกล้องต่อความแม่นยำการวัดพื้นที่ ──
วัตถุประสงค์: หาความสัมพันธ์ระหว่างความสูงของกล้องกับความคลาดเคลื่อนของการวัด
สมมติฐาน: หากไม่ calibrate ใหม่ เมื่อความสูงเปลี่ยน %error จะเพิ่มขึ้น
          (เพราะกำลังขยายของภาพเปลี่ยนตามระยะ)
ตัวแปรต้น: ความสูงกล้อง (30, 45, 60, 75, 90 ซม.)
ตัวแปรตาม: %error ของพื้นที่ที่วัดได้เทียบกับพื้นที่จริง
ตัวแปรควบคุม: วัตถุอ้างอิงเดียวกัน, มุมตั้งฉาก, แสง, เลนส์/กล้องเดิม
หลักฟิสิกส์: แบบจำลองกล้องรูเข็ม  y_ภาพ = f · Y / Z  → ขนาดในภาพแปรผกผันกับระยะ Z
วิธีทำ: วางวัตถุพื้นที่รู้ค่า (เช่น 10×10=100 ซม²) calibrate ที่ 45 ซม. ครั้งเดียว
        แล้ววัดที่ความสูงต่าง ๆ ทำซ้ำ 3 ครั้ง/ระดับ
| ความสูง (ซม.) | พื้นที่จริง (ซม²) | วัดได้เฉลี่ย (ซม²) | %error |
|--------------|------------------|---------------------|--------|
|      30      |       100        |                     |        |
|      45      |       100        |                     |        |
|      60      |       100        |                     |        |
|      75      |       100        |                     |        |
|      90      |       100        |                     |        |
การวิเคราะห์: วาดกราฟ %error vs ความสูง → อธิบายด้วยกำลังขยาย และสรุปว่าต้อง
             calibrate ตามความสูงที่ติดตั้งจริง

── การทดลองที่ 2: ผลของมุมกล้องต่อการบิดเบือนภาพ ──
วัตถุประสงค์: แสดงการบิดเบือนเชิงมุม (perspective distortion) ทางทัศนศาสตร์
สมมติฐาน: เมื่อมุมกล้องเบนจากแนวตั้งฉากมากขึ้น พื้นที่ที่วัดได้จะคลาดเคลื่อนมากขึ้น
ตัวแปรต้น: มุมเอียงกล้องจากแนวดิ่ง (0°, 15°, 30°, 45°)
ตัวแปรตาม: %error ของพื้นที่
ตัวแปรควบคุม: วัตถุ, ความสูง, แสง, calibrate ที่ 0°
หลักฟิสิกส์: การฉายภาพเชิงมุม — ความยาวที่ฉาย ≈ ความยาวจริง × cos(θ) ทำให้รูปทรง
            "หด" ตามแนวเอียง (foreshortening)
| มุม (°) | พื้นที่จริง | วัดได้เฉลี่ย | %error |
|--------|-----------|-------------|--------|
|    0   |           |             |        |
|   15   |           |             |        |
|   30   |           |             |        |
|   45   |           |             |        |
การวิเคราะห์: กราฟ %error vs มุม + เทียบกับแนวโน้ม cos(θ)

── การทดลองที่ 3: ผลของการ calibrate โฮโมกราฟี ──
วัตถุประสงค์: พิสูจน์ว่าการแปลงโฮโมกราฟีช่วยลดความคลาดเคลื่อน
สมมติฐาน: การวัดแบบ calibrate (homography) ให้ %error ต่ำกว่าการใช้สเกลคงที่
ตัวแปรต้น: วิธีวัด (สเกลคงที่ vs โฮโมกราฟี)
ตัวแปรตาม: %error ของพื้นที่
ตัวแปรควบคุม: วัตถุชุดเดียวกัน, ตำแหน่งกล้อง, แสง
หลักฟิสิกส์: โฮโมกราฟีคือเมทริกซ์ 3×3 ที่จับคู่ระนาบภาพกับระนาบถนนจริง
            แก้การบิดเบือนจากมุม/ความสูงได้พร้อมกัน
| ชิ้นที่ | พื้นที่จริง | สเกลคงที่ (ซม²) | %error | โฮโมกราฟี (ซม²) | %error |
|--------|-----------|------------------|--------|------------------|--------|
|   1    |           |                  |        |                  |        |
|   2    |           |                  |        |                  |        |
|  ...   |           |                  |        |                  |        |
| เฉลี่ย |           |                  |        |                  |        |
การวิเคราะห์: เทียบ %error เฉลี่ยของสองวิธี

── การทดลองที่ 4: ความละเอียดเชิงพื้นที่ (ซม./พิกเซล) ──
วัตถุประสงค์: หาว่าที่ความสูงต่าง ๆ 1 พิกเซลแทนกี่เซนติเมตร และตรวจจับขนาดเล็กสุด
             ได้เท่าใด
สมมติฐาน: ยิ่งกล้องสูง 1 พิกเซลยิ่งแทนพื้นที่จริงมากขึ้น → ตรวจจับของเล็กได้ยากขึ้น
ตัวแปรต้น: ความสูงกล้อง
ตัวแปรตาม: ระยะต่อพิกเซล (ซม./พิกเซล) และขนาดเล็กสุดที่ยังตรวจจับได้ (ซม.)
ตัวแปรควบคุม: กล้อง/เลนส์, ความละเอียดภาพ, แสง
หลักฟิสิกส์: Ground Sampling Distance (GSD) = (ขนาดพิกเซล × ความสูง) / ระยะโฟกัส
วิธีทำ: วางไม้บรรทัดในภาพ นับพิกเซลต่อ 1 ซม. ที่แต่ละความสูง และทดสอบวัตถุ
        ขนาดเล็กลงเรื่อย ๆ จนระบบเริ่มตรวจไม่พบ
| ความสูง (ซม.) | ซม./พิกเซล | ขนาดเล็กสุดที่ตรวจพบ (ซม.) |
|--------------|-----------|-----------------------------|
|      30      |           |                             |
|      60      |           |                             |
|      90      |           |                             |
การวิเคราะห์: กราฟ GSD vs ความสูง → เลือกความสูงติดตั้งที่เหมาะสม

── การทดลองที่ 5: ผลของความสว่างต่อการตรวจจับ ──
วัตถุประสงค์: หาช่วงความสว่างที่ระบบตรวจจับได้ดี
สมมติฐาน: ความสว่างต่ำเกินหรือสูงจ้าเกินไปทำให้ความเชื่อมั่น/อัตราการตรวจจับลดลง
ตัวแปรต้น: ความสว่าง (lux) — เช่น ~50, ~500, ~1000, ~5000
ตัวแปรตาม: ความเชื่อมั่นเฉลี่ย (%) และอัตราตรวจจับสำเร็จ (ครั้ง/10)
ตัวแปรควบคุม: ตัวอย่างความเสียหายเดียวกัน, ระยะ, มุม
หลักฟิสิกส์: โฟโตเมตรี — ความสว่าง (illuminance, lux) มีผลต่ออัตราส่วนสัญญาณต่อ
            สัญญาณรบกวน (SNR) ของภาพ
| ความสว่าง (lux) | ความเชื่อมั่นเฉลี่ย (%) | ตรวจจับสำเร็จ (/10) |
|-----------------|-------------------------|----------------------|
|   ~50 (มืด)     |                         |                      |
|   ~500          |                         |                      |
|  ~1000          |                         |                      |
| ~5000 (จ้า)     |                         |                      |
การวิเคราะห์: กราฟความเชื่อมั่น vs lux → ช่วงแสงที่เหมาะสม

── การทดลองที่ 6: ผลของพื้นผิวเปียก/แห้ง (การสะท้อนของแสง) ──
วัตถุประสงค์: ศึกษาผลของการสะท้อนแบบกระจก (เปียก) vs กระจาย (แห้ง) ต่อการวัด
สมมติฐาน: ผิวเปียกสะท้อนแสงแบบกระจกทำให้เกิดแสงจ้า/เงา ความเชื่อมั่นลดลงและ
          %error เพิ่มขึ้น
ตัวแปรต้น: สภาพผิว (แห้ง / เปียก)
ตัวแปรตาม: ความเชื่อมั่น (%) และ %error ของพื้นที่
ตัวแปรควบคุม: ตัวอย่างเดียวกัน, แสง, มุม, ความสูง
หลักฟิสิกส์: การสะท้อนแบบกระจาย (Lambertian, ผิวแห้ง) vs การสะท้อนแบบกระจก
            (specular, ผิวเปียก) และปรากฏการณ์ Fresnel
| สภาพผิว | ความเชื่อมั่น (%) | พื้นที่จริง | วัดได้ | %error |
|--------|-------------------|-----------|--------|--------|
| แห้ง   |                   |           |        |        |
| เปียก  |                   |           |        |        |
(เสริม) ทดลองใส่ฟิลเตอร์โพลาไรซ์เพื่อลดแสงจ้าจากผิวเปียก แล้ววัดซ้ำ →
        แสดงหลักการโพลาไรเซชันของแสงสะท้อน (มุมบรูว์สเตอร์)
การวิเคราะห์: เทียบผลเปียก/แห้ง (และก่อน/หลังใส่ฟิลเตอร์)

── การทดลองที่ 7: ตรวจสอบปริมาตรและมวลของวัสดุซ่อม ──
วัตถุประสงค์: พิสูจน์ว่าปริมาณทางฟิสิกส์ที่ระบบคำนวณ (ปริมาตร/มวล) ตรงกับความจริง
สมมติฐาน: ปริมาตร/มวลที่ระบบคำนวณ (V=A·h, m=ρV) ต่างจากค่าที่วัดจริง ภายใน ±X%
ตัวแปรต้น: หลุมจำลองพื้นที่/ความหนาต่าง ๆ (เช่น ถาด/แม่พิมพ์ที่รู้ขนาด)
ตัวแปรตาม: ปริมาตร/มวลระบบ vs วัดจริง (%diff)
ตัวแปรควบคุม: วัสดุเดียวกัน, ความหนาแน่นเดียวกัน
หลักฟิสิกส์: V = A × h ,  m = ρV ; วัดความหนาแน่นจริง ρ = m/V ของวัสดุตัวอย่าง
วิธีทำ: (ก) วัดความหนาแน่นวัสดุ: ชั่งมวลตัวอย่าง หารด้วยปริมาตร → ρ
        (ข) เติมวัสดุลงแม่พิมพ์ที่รู้พื้นที่/ความหนา ชั่งมวลจริง เทียบกับ m ที่ระบบคำนวณ
| ตัวอย่าง | พื้นที่ A (ตร.ม.) | ความหนา h (ม.) | ปริมาตรระบบ | มวลระบบ (กก.) | มวลจริง (กก.) | %diff |
|---------|-------------------|-----------------|-------------|----------------|----------------|-------|
|    1    |                   |                 |             |                |                |       |
|    2    |                   |                 |             |                |                |       |
การวิเคราะห์: เทียบมวลระบบ vs จริง → ความแม่นยำของการแปลงเป็นปริมาณทางฟิสิกส์

── การทดลองที่ 8 (เสริม): การขยายตัวเชิงความร้อนของวัสดุ ──
วัตถุประสงค์: สาธิตที่มาเชิงฟิสิกส์ของ "รอยแตกจากความร้อน" บนถนน
สมมติฐาน: วัสดุยืดตัวมากขึ้นเมื่ออุณหภูมิสูงขึ้นตาม ΔL = αLΔT
ตัวแปรต้น: อุณหภูมิ (เช่น ให้ความร้อนแท่งวัสดุ วัด ΔT)
ตัวแปรตาม: การยืดตัว ΔL
ตัวแปรควบคุม: วัสดุ/ความยาวเริ่มต้นเดียวกัน
หลักฟิสิกส์: ΔL = αLΔT ; ความเค้นจากความร้อนเมื่อถูกยึด σ = EαΔT → นำไปสู่รอยแตก
| อุณหภูมิ (°C) | ความยาว L (มม.) | ΔL (มม.) |
|--------------|------------------|----------|
|    25        |                  |    0     |
|    40        |                  |          |
|    60        |                  |          |
การวิเคราะห์: กราฟ ΔL vs ΔT หาค่า α และเชื่อมโยงว่าทำไมถนนไทยแตกจากความร้อนง่าย

  • ทุกการทดลอง: ระบุสมมติฐาน + ตัวแปรต้น/ตาม/ควบคุม ให้ชัด
  • วัดค่าจริง (ground truth) ด้วยเครื่องมือมาตรฐานเสมอ แล้วคิด %error
  • ทำซ้ำ ≥3–5 ครั้ง รายงานค่าเฉลี่ย ± SD
  • วาดกราฟหาแนวโน้ม/สมการ/R² (เช่น %error vs มุม, ΔL vs ΔT)
  • เชื่อมทุกผลกลับหลักฟิสิกส์: แบบจำลองกล้องรูเข็ม, การฉายภาพเชิงมุม,
    การสะท้อนของแสง (กระจก/กระจาย/โพลาไรซ์), ความหนาแน่น, การขยายตัวเชิงความร้อน
  • สรุปให้ชัด: ปัจจัยฟิสิกส์ใดสำคัญที่สุด และระบบแม่นยำในเงื่อนไขใด
