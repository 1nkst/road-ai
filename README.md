# ROAD AI

AI-powered road damage detection system using computer vision.
Built for the depa innovation competition.

## Hardware
- Raspberry Pi 4/5
- Pi Camera v3 / USB webcam
- GPS module (NEO-6M)
- 4G LTE dongle

## Components
- `edge/` — Raspberry Pi inference code (Flask + Roboflow)
- `webapp/` — Live monitoring dashboard
- `docs/` — Project proposal
